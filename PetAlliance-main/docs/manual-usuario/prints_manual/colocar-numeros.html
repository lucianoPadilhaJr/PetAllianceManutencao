Números desta tela

Como usar:
1. Clique sobre o elemento na imagem para soltar o próximo número (na ordem da legenda).
2. Arraste o número para ajustar a posição.
3. Clique em um número e aperte Delete para removê-lo.
4. Clique em Salvar PNG e salve o arquivo com o mesmo nome dentro da pasta prints_manual (substitua o original).
Salvar TODAS (1 ZIP) baixa um único arquivo com todas as telas numeradas (o Chrome bloqueia vários downloads de uma vez — por isso o "Salvar todas" antigo não salvava).
Exportar posições baixa um .json com as posições — pode me enviar que eu gero as imagens automaticamente.
